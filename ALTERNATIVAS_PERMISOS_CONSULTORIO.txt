========================================
ALTERNATIVAS PARA AGREGAR PERMISOS
========================================

OPCIÓN 1: Comando Artisan (LA MÁS FÁCIL) ✅✅✅
----------------------------------------------
Ejecutar en el servidor:

cd /home/audaz.site/public_html
php artisan consultorio:install-permissions

¡Eso es todo! Un solo comando.


OPCIÓN 2: Usando Tinker con archivo
------------------------------------
cd /home/audaz.site/public_html
php artisan tinker < agregar-permisos-consultorio.php


OPCIÓN 3: Usando Tinker manual (línea por línea)
-------------------------------------------------
cd /home/audaz.site/public_html
php artisan tinker

Luego copiar LÍNEA POR LÍNEA (presionar Enter después de cada una):

$permissions = ['consultorio.view', 'consultorio.create', 'consultorio.edit', 'consultorio.delete'];
foreach ($permissions as $p) { \Spatie\Permission\Models\Permission::firstOrCreate(['name' => $p, 'guard_name' => 'web']); }
$admin = \Spatie\Permission\Models\Role::where('name', 'like', 'Admin#%')->first();
if ($admin) { $admin->givePermissionTo($permissions); echo "✅ Completado\n"; }
exit


OPCIÓN 4: MySQL directo
------------------------
mysql -u root -p audaz_pos < add-consultorio-permissions.sql


OPCIÓN 5: Desde phpMyAdmin (si tienes acceso)
----------------------------------------------
1. Ir a phpMyAdmin
2. Seleccionar base de datos: audaz_pos
3. Click en pestaña "SQL"
4. Pegar el contenido de add-consultorio-permissions.sql
5. Click en "Continuar"
